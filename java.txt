JpaRepository => CRUD 기능 있음

+ QueryDSL : 동적인 쿼리 작성
QuerydslPredicateExecutor 인터페이스 제공 : 정해진 메서드로 조건 검색, 쿼리 작성 자유도가 낮은 편

QuerydslRepositorySupport 추상 클래스 제공 : 직접 쿼리 작성 가능, 쿼리 작성 자유도가 높은 편

인터페이스
interface Parent{

        void sum();      (중괄호가 없음)
        void div();
}

추상 클래스
abstract class Parent{

        // 추상 메서드
        abstract void sum();
        void div(){
                ...
        }
}

// 구현 클래스가 필요함
class Child implements Parent{
        void sum(){
                ...
        };
        void div(){
                ...
        };
}

추상 클래스
class Child extends Parent{

      void sum(){
        ...
      }
}

인터페이스는 틀만 만들어줌 = template



class Parent{
        private int age;

        public Parent(int age){
                this.age = age;
        }

}

class Child extends Parent{
        private String name;

        public Child(int age, String name){
                super(age);
                this.name = name;
        }
}

초기화 할때:  
Child child = new Child(20, "홍길동");

Child child = new Child();
child.setAge(25);
child.setName("홍길동")

builder() 사용시:
